the manifest entry for that card's index) and one empty overlay element
<div class="kind-scrim" aria-hidden="true"></div>. NOTHING ELSE CHANGES:
zero word changes, every title/body/link byte-identical, same element order,
same classes. Cards with no manifest entry (missing file, missing index)
render with NO background image and NO scrim — honestly empty, exactly as
today (the old white card + the new CSS fallback background-color only
applies when the photo exists; without a photo the card keeps its old
white look via the print-style fallback — see note below).

NOTE ON THE NO-PHOTO FALLBACK: the NEW code below adds class
"kind-card has-photo" ONLY when a manifest entry with a src exists, and
plain "kind-card" otherwise. The CSS snippet scopes every photo rule
(dark background-color, light text, scrim, gold links) under
.kind-card.has-photo, so a card with no photo keeps the old white card
exactly (dark text on white) and can never strand light text on a dark
card. The dark background-color on .has-photo is only a load fallback
while the photo downloads.

--- NEW CODE (exact replacement) ---
        case 'kinds': {
            $cards = '';
            // Task 5: card backgrounds from qa/manifest-kinds-F.php (copied
            // to site/data/manifest-kinds.php by the coordinator). Indexed
            // by card order; a missing entry renders the card with no photo.
            $kindsMedia = $GLOBALS['KINDS_MEDIA'] ?? null;
            if ($kindsMedia === null) {
                $kindsFile = __DIR__ . '/../data/manifest-kinds.php';
                $kindsMedia = is_file($kindsFile) ? require $kindsFile : [];
                $GLOBALS['KINDS_MEDIA'] = $kindsMedia;
            }
            $ki = 0;
            foreach ($b['items'] as $k) {
                $km = $kindsMedia['kinds']['home'][$ki] ?? null;
                $cls = 'kind-card';
                $style = '';
                $scrim = '';
                if (!empty($km['src'])) {
                    $cls .= ' has-photo';
                    $style = ' style="background-image:url(' . esc($km['src']) . ')"';
                    $scrim = '<div class="kind-scrim" aria-hidden="true"></div>';
                }
                $cards .= '<article class="' . $cls . '"' . $style . '>' . $scrim . '<h3>' . esc($k['title']) . '</h3>'
                    . '<p>' . render_segments($k['body']) . '</p></article>';
                $ki++;
            }
            return '<div class="kinds-grid">' . $cards . '</div>';
        }
